一、故障现象

二、原因分析

官方确认

错误代码 0x800706D9 表示系统所需的服务没有运行，或者服务配置异常。常见关联服务包括：

  • RPC Endpoint Mapper（RPC 终结点映射器）
  • Remote Procedure Call（RPC，远程过程调用）
  • Windows Defender Firewall（Windows Defender 防火墙）

本机实际情况

检查发现以下服务均正常运行：

  • RpcEptMapper：RPC 终结点映射器
  • RpcSs：远程过程调用
  • MpsSvc：Windows Defender 防火墙
  • BFE：基本筛选引擎
  • wlidsvc：Microsoft 帐户登录助手
  • InstallService：Microsoft Store 安装服务

但 StorSvc（存储服务）处于停止状态，并且被设置为“禁用”。

因此，本次故障可以确定为：StorSvc 存储服务被禁用，导致微软商店无法正常完成应用下载和安装。

六、常见状态和错误代码

状态或代码 含义
STATE : 1 STOPPED 服务已经停止
STATE : 2 START_PENDING 服务正在启动
STATE : 4 RUNNING 服务正常运行
错误 1056 服务已经在运行，无需再次启动
错误 1058 服务被禁用，必须先修改启动类型
WIN32_EXIT_CODE : 0 服务没有系统级错误

七、注意事项

  1. 相关命令需要在“管理员身份”的 CMD 中运行。
  2. StorSvc 设置为“手动/按需启动”即可，不需要强制设置为自动。
  3. 电脑重启后，StorSvc 可能再次显示“已停止”，这是按需启动服务的正常现象。
  4. 只要启动类型不是“禁用”，系统需要时便可以调用该服务。
